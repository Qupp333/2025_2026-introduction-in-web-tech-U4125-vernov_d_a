# Лабораторная работа №0

## Цель работы

Освоить базовые возможности Git и GitHub: создание репозитория, работа с ветками, коммитами и Pull Request.

## Ход работы

### 1. Создание репозитория

На GitHub был создан репозиторий для выполнения лабораторной работы.

### 2. Настройка рабочего окружения

Для работы с репозиторием использовался GitHub Desktop. Репозиторий был склонирован на локальный компьютер.

### 3. Создание README.md

Был создан файл `README.md`, содержащий описание репозитория, контактные данные и план изучения DevOps.

### 4. Создание .gitignore

Был создан файл `.gitignore` со стандартными исключениями для операционной системы и служебных файлов.

### 5. Создание ветки develop

Была создана отдельная ветка `develop`, в которой выполнялись изменения проекта.

### 6. Создание CONTRIBUTING.md

Был создан файл `CONTRIBUTING.md` с правилами участия в проекте.

### 7. Создание коммита

Изменения были сохранены в Git с сообщением:

`Initial project setup`

### 8. Создание Pull Request

Был создан Pull Request из ветки `develop` в ветку `main`.

### 9. Слияние веток

Pull Request был успешно объединён с основной веткой `main`, после чего ветка `develop` была удалена.

### 10. Добавление лицензии

В репозиторий был добавлен файл `LICENSE`.

## Результат

В результате лабораторной работы был создан и настроен GitHub-репозиторий. Были изучены базовые принципы работы с Git и GitHub: ветки, коммиты, Pull Request и слияние изменений.
