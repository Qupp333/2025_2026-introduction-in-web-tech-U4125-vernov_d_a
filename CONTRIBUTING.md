# Contributing

## Правила участия в проекте

1. Все изменения должны вноситься через отдельную ветку.
2. Перед добавлением изменений необходимо проверить их работоспособность.
3. Коммиты должны иметь понятные сообщения.
4. Изменения в ветку main вносятся через Pull Request.
5. Перед слиянием Pull Request необходимо проверить внесенные изменения.
